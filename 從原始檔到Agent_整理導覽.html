大部分不會進 Agent。照片、重複版本、名冊這類檔案佔了七成，放進去反而干擾回答。
同一份可以進兩個 Agent。例如 Ivy 有 85 份同時給教育訓練和講綱用。

02

四種分類，各是什麼意思

D 槽每份檔案都被放進其中一類。重點是：沒有任何檔案被刪掉，分類只決定「現在要不要給 Agent 用」。

可用知識來源

已匯入
484佔 14%

內容本身就是知識，可以直接回答問題。全部放進教育訓練 Agent，其中 18 份也放進講綱。

裡面有什麼

輔助參考

部分匯入
452佔 13%

有參考價值，但綁著特定年度、活動或對象。整包放進去，Agent 可能把「某一年的安排」當成通用答案。

例如
講師資料表邀請與招生公文會議紀錄、委託文件宣傳頁面課綱附表
目前去向
17 份 已進講綱（16 份講師資料表＋1 份訓練說明）435 份 先保留

不是「不要」，也不是「沒讀」。之後哪個 Agent 需要，再從這裡挑。

暫不入庫

不匯入・原檔保留
2,588佔 73%

不適合讓 Agent 讀的檔案：沒有文字內容、重複，或是個人資料。

裡面有什麼

待補讀

有密碼・打不開
30佔 1%

這 30 份都設了密碼，內容還讀不到，所以還不能判斷該分到哪一類。

從檔名看，大概是
志工名單、時數結算高鐵票、領據研討會資料保險報價與要保書
格式

拿到密碼後再打開判定。從檔名看多半是行政資料，可能最後也是暫不入庫。
